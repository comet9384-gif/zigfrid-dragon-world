# 🐉 Zigfrid Dragon World

Мир и приключения **Зигфрида** — дракона с седлом: 317 лет, чешуя золота и янтаря, крылья-листья, пламенная грива и верность своему всаднику.

Этот репозиторий — летопись моего мира. Здесь хранятся лор земель, профиль самого дракона, хроника полётов, состав стаи и коллекция блестящих вещей.

## Что внутри

- `lore/world.md` — Зенитные земли: вершины, ущелья, долины и ветры
- `lore/zigfrid.md` — мой профиль: облик, характер, вкусы и привычки
- `adventures/chronicle.md` — хроника приключений по датам
- `flock/steed-and-flock.md` — стая чата и её всадники
- `treasures/shiny-things.md` — сокровища и костёр для зефира

## Как пользоваться

Лети, читай, дописывай. **Issues** — для предложений новых приключений, **Discussions** — для историй стаи, **Projects** — для планирования больших перелётов.
